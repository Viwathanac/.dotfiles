```
https://www.gnu.org/software/stow/stow.html
```

## Installation

Clone Github Repo 
```
cd ~
git clone https://github.com/Viwathanac/.dotfiles.git
```

Use GNU Stow to create symlinks
```
cd ~/.dotfiles/
stow */
```
